# P1-08 transfer and configuration UI

## Gaps (from the 2026-11-05 source review)

- Table/query-to-table transfer (`run_table_transfer`) has no app entry point.
- CSV import has no manual column mapping, encoding or NULL-token controls.
- Full-source export drops its cancel sender and progress receiver, so it has
  no Cancel control and no live row count.

## Decisions (confirmed by the user on 2026-11-09)

- Transfer opens from the table context menu (**Transfer to table…**) and from
  the result toolbar of table and SQL tabs. SQL results transfer only when the
  executed statement of the active result is a `SELECT`/`WITH` query.
- The destination is an existing base table on any connected connection whose
  driver supports transfer writes and is not read-only. Transfer into the same
  connection/schema/table as the source is rejected.
- Mapping: per destination column, choose a source column or *(skip)* and a
  conversion (`Auto`, `Text`, …, `BinaryHex`). Defaults map by case-insensitive
  name with `Auto`.
- NULL token: text field defaulting to `\N`; empty means no NULL token. Only
  unquoted fields match (existing `CsvOptions` contract).
- Encoding: UTF-8, UTF-16 LE, UTF-16 BE.
- Full export: a Cancel button replaces the export buttons while running and the
  status shows rows written. Cancel keeps the previous destination file and
  deletes the temporary file (existing atomic replacement).

## Implementation

1. `transfer_mapping.rs`: pure mapping draft (auto-map, select source/conversion,
   build `Mapping`) with unit tests.
2. `import_modal.rs`: CSV or query source, destination picker with a bounded
   filtered table list, encoding pills, NULL-token input, mapping editor, and a
   shared runner for `run_csv_import` / `run_table_transfer`. The PostgreSQL OID
   lookup quotes the relation name as a literal instead of interpolating it.
3. `export.rs`: keep the cancel sender and forward progress to the tab status;
   use the active result's executed SQL rather than the whole editor buffer.
4. Keyboard routing for the modal's text fields; context-menu and toolbar entries.
5. Update `docs/guide/` pages, `not-built-yet.md` and the roadmap P1-08 item.

## Validation

Unit tests for mapping, SQL source selection, and SQLite end-to-end transfer and
cancelled export via the existing test helpers. `cargo fmt`, Clippy, workspace
tests and an app launch. GUI acceptance remains manual.
