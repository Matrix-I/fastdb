## Technical approach

Reuse the pinned script runner and its operation ownership, cancellation and
raw pager; never explain through a fresh connection. Keep provider parsing in
small db-wire modules and UI state/actions in app workspace modules. Bound
saved output and tree sizes, keep filesystem/parser work off rendering, and
preserve existing PostgreSQL/SQLite behavior. No new dependencies are planned.

Official syntax references: MySQL 8.4 EXPLAIN statement/output documentation
and MariaDB EXPLAIN/ANALYZE FORMAT=JSON documentation. ODBC vendor syntax will
be checked against official engine documentation before implementation.
