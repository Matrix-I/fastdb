# Provider logo sources

PostgreSQL, MySQL and SQLite logos are the original SVG variants from
[Devicon](https://github.com/devicons/devicon), retrieved 2026-11-05.
The vector assets replace the previous 16 × 16 PNGs and are used by both the
connection picker and navigator. The upstream artwork is unchanged.

GPUI 0.2.2's `img` loader rasterizes these 128 × 128 canvases at 2× (256 × 256),
which exceeds the 88 physical pixels needed by the 44px picker icons on Retina.

Devicon's MIT notice is retained in [DEVICON-LICENSE.txt](DEVICON-LICENSE.txt).
Brand names and marks remain the property of their respective owners.
